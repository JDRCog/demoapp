# PAY-4821: Cross-border wires — MT103 → ISO 20022 pacs.008 (CBPR+)

**Type:** Story | **Component:** cross-border-wire-service | **Epic:** SWIFT ISO 20022 coexistence end (Nov 2025)

## Description

SWIFT ends MT/MX coexistence for cross-border payment instructions. Outbound customer credit transfers from `CrossBorderWireService` must be able to produce a CBPR+ compliant `pacs.008.001.08` with a `head.001.001.02` Business Application Header.

Ship behind `wire.iso20022.enabled` (default `false`). Ops will flip it per environment after SWIFT readiness testing.

## Acceptance criteria

1. Flag off: MT103 output and topic byte-for-byte unchanged.
2. Flag on: BAH + pacs.008 published to `payments.crossborder.pacs008.outbound.v1` (already provisioned), keyed by UETR.
3. Every row in [PAY-4821-field-mapping.csv](PAY-4821-field-mapping.csv) is implemented and covered by a field-by-field parity test.
4. ≥ 85% line coverage; CI green with the flag on and off.
5. No PII in logs, exceptions or fixtures.
